JOGO DO SEMÁFORO

Semáforo is a digital adaptation of the traditional mathematical board game, developed as part of the Programming Laboratory curriculum. Notably, this project represents my very first undergraduate build, focusing on translating physical, rule-based tabletop mechanics into a fluid software loop using Python.

The architecture was built following a strict decoupled approach. Before rendering any pixels, the core backend engine was engineered to run completely standalone within a text-based console environment. This structure allowed our team to safely prototype and isolate the game's victory matrices, piece tier transitions, and active player contexts from any visual dependencies.

Once the foundational logic was fully validated, the application transitioned into a high-fidelity graphical user interface layer powered by Pygame. The integration introduces memory-optimized blitting routines, responsive layout tracking, and a randomized algorithmic agent for automated single-player interaction.

Application Interface Matrix

01Intro Screen: Main menu application gateway.
02Secondary Menu: Match parameter configuration.
03Mode Selection: Choice between Single-player and PVP modes.
04Interface Deployment: Registering user data handles.
05Board Canvas: Pure 3x4 board layout architecture initialization.
06Gameplay Loop: Live turn sequence tracking and token piece tier evolution.
07Win Validation: Real-time evaluation of winning branches and victory screen.
08Rule Book: Integrated modal view covering board restrictions and win conditions.
