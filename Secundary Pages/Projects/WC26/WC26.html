FIFA WORLD CUP 2026
STICKER ALBUM

I was responsible for developing a complete digital sticker album experience, building the front-end architecture using HTML, CSS, and JavaScript. The interface was meticulously designed to bridge nostalgia with modern interactive web capabilities.

The core mechanics rely on a robust REST API and an SQL database to manage user accounts, handle the virtual sticker collections, and facilitate trading functionalities between players. This allows players to securely open packs and track their completion progress in real-time.

All visual assets, including the dynamic player cards, mascots, and highly detailed stadium backgrounds, were crafted and optimised using Adobe Photoshop. This ensured high-fidelity graphics and a premium user experience across all screen sizes.
